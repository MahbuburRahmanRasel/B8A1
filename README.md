
## Assignment Overview

1\. Problem 1 – Optional Parameters: A function with an optional multiplier and a default value of 2.

2\. Problem 2 – Union Types & Type Narrowing: Processing string, number, and boolean inputs using `typeof`.

3\. Problem 3 – Readonly Tuples: Handling readonly coordinate tuples and returning formatted location strings.

4\. Problem 4 – Generic Functions & Rest Parameters: Combining multiple arrays of the same data type using generics and rest parameters.

5\. Problem 5 – Interfaces & Array Filtering: Defining a Course interface and filtering published courses based on minimum student enrollment.

6\. Problem 6 – Generics & Keyof Constraint: Extracting object property values using generics and the `keyof` constraint.

7\. Problem 7 – Classes, Inheritance & Access Modifiers: Implementing Employee and Manager classes using `protected`, `private`, and inheritance.

8\. Problem 8 – Asynchronous Programming & Promises: Handling age validation through asynchronous functions, Promise resolution, and rejection.
